NewLion Auto Post

A desktop tool for the NewLion trading-education channel. It publishes finished short videos to TikTok with the creator's own caption, cover and privacy choice, using TikTok's official Content Posting API.

  • Log in with TikTok — no password stored
  • Review caption, cover, privacy and interaction settings before every post
  • Videos and tokens stay on the creator's own computer
