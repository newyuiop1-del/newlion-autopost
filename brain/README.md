# 🧠 Brain — สมองกลเชื่อมทุกอย่างในคอม และคอมเครื่องอื่นๆ

สแกนไฟล์ในคอมทุกเครื่อง แล้วแสดงเป็นจักรวาล 3 มิติเรืองแสง:
แต่ละดาว = ไฟล์/โฟลเดอร์ · เส้น = ความเชื่อมโยง

| เส้น | ความหมาย |
|---|---|
| ขาวหนา | สมองกลาง ↔ คอมแต่ละเครื่อง |
| ฟ้า (มีอนุภาควิ่ง) | ไฟล์หนึ่งอ้างถึงอีกไฟล์ (พูดถึงชื่อไฟล์, `import` โมดูล) |
| ชมพู | ไฟล์เดียวกันที่อยู่คนละเครื่อง (ชื่อ+ขนาดตรงกัน) |
| จาง | โฟลเดอร์ → ไฟล์ข้างใน |

สีดาว: 🟠 วิดีโอ/สไลด์/คลิป · 🔵 แอป/โค้ด · 💠 โพสต์/เอกสาร · 🔴 แบรนด์/CI · 🟡 กฎ/นโยบาย/สัญญา · 🟢 ข้อมูล/ตาราง

## ใช้งาน (ต้องมีแค่ Python 3.9+ ไม่ต้องติดตั้งอะไรเพิ่ม)

**เครื่องเดียว**
```bash
python brain.py serve
# เปิด http://localhost:8765
```
ค่าเริ่มต้นจะสแกน Desktop, Documents, Downloads, Pictures, Videos ฯลฯ
อยากเลือกเอง: `python brain.py serve D:\งาน E:\คลิป`

**หลายเครื่อง (วงแลน/Wi-Fi เดียวกัน)**

1. เครื่องหลัก (ที่ต่อจอใหญ่):
   ```bash
   python brain.py serve --every 600   # ดูรหัสที่หน้าจอ
   ```
   มันจะพิมพ์คำสั่งสำหรับเครื่องอื่นให้ พร้อม IP
2. เครื่องอื่นๆ (ก๊อปโฟลเดอร์ `brain/` ไปด้วย):
   ```bash
   python brain.py push --hub http://192.168.1.10:8765 --token รหัสลับของฉัน --every 600
   ```
3. เปิดหน้าสมองที่ `http://localhost:8765/?token=รหัสลับของฉัน`

ข้ามเน็ตต่างที่ (คอมที่บ้าน ↔ ออฟฟิศ): ใช้ [Tailscale](https://tailscale.com) ให้ทุกเครื่องอยู่วงเดียวกัน แล้วใช้ IP ของ Tailscale แทน

## 🔗 เชื่อมสมอง 2 เครื่องขึ้นไป (ง่ายสุด — กดในหน้าจอ)

1. ก๊อปโฟลเดอร์ `brain/` ไปทั้ง 2 เครื่อง (ต้องมี Python — Windows ลงจาก python.org ติ๊ก "Add to PATH")
2. ดับเบิลคลิก **`เปิดสมอง-Windows.bat`** (หรือ `เปิดสมอง-Mac.command` บน Mac) ที่ทั้ง 2 เครื่อง
   - Windows ถามเรื่อง Firewall → กด **Allow / อนุญาต** (ติ๊ก Private network)
3. ที่หน้าจอ Brain ของเครื่อง B จะเห็น **"ที่อยู่เครื่องนี้: 192.168.x.x:8765 · รหัส: xxxx"**
4. ที่หน้าจอของเครื่อง A กรอก IP และรหัสของเครื่อง B → กด **🔗 เชื่อม**
5. เสร็จ — เครื่อง B จะเชื่อมกลับมาหา A เอง ทั้งสองเครื่องมีสมองเหมือนกัน sync ทุก 60 วินาที
   และจำการเชื่อมไว้ เปิดครั้งหน้าก็เชื่อมต่อเอง

ถ้าเชื่อมไม่ได้ หน้าจอจะบอกเหตุผล:
| ข้อความ | แก้ |
|---|---|
| ต่อไม่ติด | เครื่องนั้นยังไม่ได้เปิด Brain / IP หรือพอร์ตผิด |
| หมดเวลารอ | Firewall บล็อก หรือไม่ได้อยู่ Wi-Fi เดียวกัน (Wi-Fi แขก/Guest มักต่อหากันไม่ได้) |
| รหัสไม่ตรง | ดูรหัสที่หน้าจอของเครื่องนั้นใหม่ |

แบบพิมพ์คำสั่งก็ได้: `python brain.py serve --peer 192.168.1.20 --peer-token รหัสของเครื่องนั้น`

**คัดลอกสมองทั้งก้อนไปเครื่องใหม่ครั้งเดียว:** `python brain.py clone http://192.168.1.10:8765 --token รหัสลับ`

**ให้ AI บนอีกเครื่องอ่าน/ศึกษาสมอง:**
```bash
python brain.py export -o brain_export          # หรือ --from http://192.168.1.10:8765 --token ...
```
ได้ `brain_knowledge.md` (สรุปเครื่อง โฟลเดอร์ ไฟล์ศูนย์กลาง ไฟล์ซ้ำข้ามเครื่อง เส้นอ้างอิง)
และ `brain_knowledge.json` (กราฟเต็ม) — ส่งให้ Claude / AI ตัวไหนอ่านก็ได้
หรือเปิดลิงก์ "📄 สรุปความรู้ให้ AI อ่าน" ในหน้าสมอง

## ในหน้าสมอง
- คลิกดาว → ดูว่าเชื่อมกับอะไรบ้าง (คลิกรายการเพื่อบินไปหา)
- Ctrl+คลิก หรือปุ่ม "เปิดไฟล์" → เปิดโฟลเดอร์ของไฟล์นั้น (เฉพาะไฟล์บนเครื่องหลัก)
- ช่องค้นหา, ติ๊กหมวดเพื่อซ่อน/แสดง, ปุ่ม "หมุน", ปุ่ม "สแกน" สแกนเครื่องหลักใหม่

## ความปลอดภัย
- ส่งเฉพาะชื่อไฟล์ path ขนาด เวลา และเส้นเชื่อม — **ไม่ส่งเนื้อหาไฟล์**
- เครื่องอื่นต้องมีรหัส (สร้างอัตโนมัติ เก็บใน `data/token.txt`) จึงจะอ่านสมองได้; หน้าจอบนเครื่องตัวเองไม่ต้องใช้รหัส; ไม่อยากให้เครื่องอื่นเข้าเลยใช้ `--local-only`
- ข้อมูลเก็บใน `brain/data/` (ไม่ถูก commit)
- ข้าม `.git`, `node_modules`, ไฟล์ซ่อน, โฟลเดอร์ระบบ; จำกัด 4000 ไฟล์/เครื่อง (`--max-files`)
