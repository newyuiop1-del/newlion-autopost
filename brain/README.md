# 🧠 Brain — สมองกลเชื่อมทุกอย่างในคอม และคอมเครื่องอื่นๆ

สแกนไฟล์ในคอมทุกเครื่อง แล้วแสดงเป็นจักรวาล 3 มิติเรืองแสง:
แต่ละดาว = ไฟล์/โฟลเดอร์ · เส้น = ความเชื่อมโยง

| เส้น | ความหมาย |
|---|---|
| ขาวหนา | สมองกลาง ↔ คอมแต่ละเครื่อง |
| ฟ้า (มีอนุภาควิ่ง) | ไฟล์หนึ่งอ้างถึงอีกไฟล์ (พูดถึงชื่อไฟล์, `import` โมดูล) |
| ชมพู | ไฟล์เดียวกันที่อยู่คนละเครื่อง (ชื่อ+ขนาดตรงกัน) |
| จาง | โฟลเดอร์ → ไฟล์ข้างใน |

สีดาว: 🟠 วิดีโอ/สไลด์/คลิป · 🔵 แอป/โค้ด · 💠 โพสต์/เอกสาร · 🔴 แบรนด์/CI · 🟡 กฎ/นโยบาย/สัญญา · 🟢 ข้อมูล/ตาราง

## เริ่มใช้ (3 นาที)

1. **ดาวน์โหลด** โฟลเดอร์ `brain/` ไปไว้ในคอมทุกเครื่อง
2. **ดับเบิลคลิก**
   - Mac: `เปิดสมอง-Mac.command` — ครั้งแรก Mac อาจบอกว่า "เปิดไม่ได้" → **คลิกขวา → Open → Open**
   - Windows: `เปิดสมอง-Windows.bat` — ถ้าถาม Firewall กด **Allow / อนุญาต**
   - ยังไม่มี Python? ไฟล์จะเปิดหน้าดาวน์โหลดให้เอง
3. หน้าสมองเปิดขึ้นมาเองใน browser (`http://localhost:8765`)

## 🔗 เชื่อมคอม (เหมือนจับคู่ Bluetooth)

1. เปิด Brain ทั้ง 2 เครื่อง ต่อ **Wi-Fi เดียวกัน**
2. เครื่องไหนก็ได้ กด **＋ เชื่อมคอม** (ปุ่มจะกระพริบเมื่อเจอเครื่องใหม่)
3. เครื่องอีกฝั่งโผล่ในรายการเอง → กด **เชื่อม**
4. พิมพ์ **รหัส 6 หลัก** ที่แสดงบนหน้าจอของเครื่องนั้น → เสร็จ ✅

ทั้งสองเครื่องจะมีสมองเดียวกัน sync ทุก 60 วินาที และจำกันไว้ เปิดครั้งหน้าก็เชื่อมเอง
จะเพิ่มเครื่องที่ 3, 4 ก็ทำแบบเดียวกัน

ไม่เจอในรายการ? กด "ไม่เจอ? ใส่ IP เอง" แล้วใส่ IP + รหัสที่เห็นบนหน้าจอเครื่องนั้น
ถ้าเชื่อมไม่ได้ หน้าจอจะบอกเหตุผล (ยังไม่เปิด Brain / Firewall บล็อก / รหัสไม่ตรง / Wi-Fi แขก)

ต่างที่กัน (บ้าน ↔ ออฟฟิศ): ลง [Tailscale](https://tailscale.com) ทุกเครื่อง แล้วใช้ "ใส่ IP เอง" ด้วย IP ของ Tailscale

## สำหรับคนชอบพิมพ์คำสั่ง
```bash
python3 brain.py serve D:\งาน E:\คลิป        # เลือกโฟลเดอร์ที่จะสแกนเอง
python3 brain.py serve --peer 192.168.1.20 --peer-token 123456
python3 brain.py serve --local-only              # ไม่ให้เครื่องอื่นเชื่อมเข้ามา
```

**คัดลอกสมองทั้งก้อนไปเครื่องใหม่ครั้งเดียว:** `python brain.py clone http://192.168.1.10:8765 --token รหัสลับ`

**ให้ AI บนอีกเครื่องอ่าน/ศึกษาสมอง:**
```bash
python brain.py export -o brain_export          # หรือ --from http://192.168.1.10:8765 --token ...
```
ได้ `brain_knowledge.md` (สรุปเครื่อง โฟลเดอร์ ไฟล์ศูนย์กลาง ไฟล์ซ้ำข้ามเครื่อง เส้นอ้างอิง)
และ `brain_knowledge.json` (กราฟเต็ม) — ส่งให้ Claude / AI ตัวไหนอ่านก็ได้
หรือเปิดลิงก์ "📄 สรุปความรู้ให้ AI อ่าน" ในหน้าสมอง

## ในหน้าสมอง
- คลิกดาว → ดูว่าเชื่อมกับอะไรบ้าง (คลิกรายการเพื่อบินไปหา)
- Ctrl+คลิก หรือปุ่ม "เปิดไฟล์" → เปิดโฟลเดอร์ของไฟล์นั้น (เฉพาะไฟล์บนเครื่องหลัก)
- ช่องค้นหา, ติ๊กหมวดเพื่อซ่อน/แสดง, ปุ่ม "หมุน", ปุ่ม "สแกน" สแกนเครื่องหลักใหม่

## ความปลอดภัย
- ส่งเฉพาะชื่อไฟล์ path ขนาด เวลา และเส้นเชื่อม — **ไม่ส่งเนื้อหาไฟล์**
- เครื่องอื่นต้องมีรหัสจับคู่ 6 หลัก (สร้างอัตโนมัติ เก็บใน `data/token.txt`) จึงจะอ่านสมองได้; ใส่ผิด 8 ครั้งล็อก 2 นาที; หน้าจอบนเครื่องตัวเองไม่ต้องใช้รหัส; ไม่อยากให้เครื่องอื่นเข้าเลยใช้ `--local-only`
- ข้อมูลเก็บใน `brain/data/` (ไม่ถูก commit)
- ข้าม `.git`, `node_modules`, ไฟล์ซ่อน, โฟลเดอร์ระบบ; จำกัด 4000 ไฟล์/เครื่อง (`--max-files`)

## แก้หน้าตา

```bash
cd viewer-src && npm install && npm run build   # ได้ ../viewer.bundle.js
```
`viewer.bundle.js` ถูก commit ไว้แล้ว จึงใช้งานได้แบบออฟไลน์ไม่ต้องพึ่ง CDN
